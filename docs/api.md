# HTTP API — Гофермарт

Накопительная система лояльности «Гофермарт». Сводная таблица эндпоинтов и детализация кодов ответов.

## Сводная таблица

| Метод | Путь                       | Запрос           | Ответ                  | Auth | Описание                                            |
|-------|----------------------------|------------------|------------------------|------|-----------------------------------------------------|
| POST  | `/api/user/register`       | application/json | application/json (200) | —    | Регистрация + автоматическая аутентификация        |
| POST  | `/api/user/login`          | application/json | application/json (200) | —    | Аутентификация                                      |
| POST  | `/api/user/orders`         | text/plain       | только status code     | JWT  | Загрузка номера заказа (проверка алгоритмом Луна)   |
| GET   | `/api/user/orders`         | —                | application/json \| 204| JWT  | Список заказов: статусы, начисления                  |
| GET   | `/api/user/balance`        | —                | application/json       | JWT  | Текущий баланс: `current` + `withdrawn`             |
| POST  | `/api/user/balance/withdraw` | application/json | только status code   | JWT  | Списание баллов в счёт оплаты нового заказа          |
| GET   | `/api/user/withdrawals`    | —                | application/json \| 204| JWT  | История списаний                                     |

Авторизация всех хендлеров, кроме `register` и `login`, — заголовок `Authorization: Bearer <JWT>`.

## Детализация по эндпоинтам

### POST /api/user/register

Регистрация по паре логин/пароль. При успехе — автоматическая аутентификация (JWT).

```json
{ "login": "<login>", "password": "<password>" }
```

| Код | Значение                                   |
|-----|--------------------------------------------|
| 200 | Пользователь зарегистрирован и аутентифицирован |
| 400 | Неверный формат запроса                    |
| 409 | Логин уже занят                            |
| 500 | Внутренняя ошибка сервера                  |

См. диаграммы: [register.mmd](../schemas/api/register.mmd), [flowchart-register.mmd](../schemas/api/flowchart-register.mmd)

### POST /api/user/login

Аутентификация по паре логин/пароль.

```json
{ "login": "<login>", "password": "<password>" }
```

| Код | Значение                    |
|-----|-----------------------------|
| 200 | Успешная аутентификация     |
| 400 | Неверный формат запроса     |
| 401 | Неверная пара логин/пароль  |
| 500 | Внутренняя ошибка сервера   |

### POST /api/user/orders

Загрузка номера заказа. Тело — номер заказа (последовательность цифр) как plain text.
Номер проверяется алгоритмом Луна.

```
Content-Type: text/plain

12345678903
```

| Код | Значение                                    |
|-----|---------------------------------------------|
| 200 | Номер уже был загружен этим пользователем   |
| 202 | Новый номер принят в обработку              |
| 400 | Неверный формат запроса                     |
| 401 | Пользователь не аутентифицирован            |
| 409 | Номер уже загружен другим пользователем     |
| 422 | Неверный формат номера заказа              |
| 500 | Внутренняя ошибка сервера                   |

### GET /api/user/orders

Список заказов пользователя, отсортированный по времени загрузки от новых к старым.
Формат даты — RFC3339.

| Код | Значение                          |
|-----|-----------------------------------|
| 200 | Успех (см. формат ниже)           |
| 204 | Нет данных для ответа             |
| 401 | Пользователь не авторизован       |
| 500 | Внутренняя ошибка сервера         |

```json
[
    {
        "number": "9278923470",
        "status": "PROCESSED",
        "accrual": 500,
        "uploaded_at": "2020-12-10T15:15:45+03:00"
    }
]
```

Статусы: `NEW`, `PROCESSING`, `INVALID`, `PROCESSED`.
`accrual` присутствует только при ненулевом начислении.

### GET /api/user/balance

Текущий баланс счёта лояльности.

| Код | Значение                    |
|-----|-----------------------------|
| 200 | Успех (см. формат ниже)     |
| 401 | Пользователь не авторизован |
| 500 | Внутренняя ошибка сервера   |

```json
{ "current": 500.5, "withdrawn": 42 }
```

### POST /api/user/balance/withdraw

Списание баллов в счёт оплаты нового заказа. Для успешного списания достаточно
успешной регистрации запроса — внешние системы не привлекаются.

```json
{ "order": "2377225624", "sum": 751 }
```

| Код | Значение                      |
|-----|-------------------------------|
| 200 | Успешная обработка запроса    |
| 401 | Пользователь не авторизован   |
| 402 | На счету недостаточно средств |
| 422 | Неверный номер заказа         |
| 500 | Внутренняя ошибка сервера     |

### GET /api/user/withdrawals

История вывода средств, отсортированная по времени от новых к старшим.
Формат даты — RFC3339.

| Код | Значение                      |
|-----|-------------------------------|
| 200 | Успех (см. формат ниже)       |
| 204 | Нет ни одного списания        |
| 401 | Пользователь не авторизован   |
| 500 | Внутренняя ошибка сервера     |

```json
[
    {
        "order": "2377225624",
        "sum": 500,
        "processed_at": "2020-12-09T16:09:57+03:00"
    }
]
```
